# 01: 빈 방명록 페이지와 개발 기반

**What to build:** 방문자가 페이지에 들어가면 제목, `개발자: 이동규 (202404265)`, 그리고 글 목록 영역이 보인다. 목록은 실제 DB에서 조회하며, 글이 없으면 "아직 글이 없습니다"가 표시된다. 이후 티켓이 올라탈 기반(글 테이블 스키마, DB 초기화 스크립트, DB 연결을 주입받는 방명록 모듈, Vitest + PGlite 테스트 환경)을 함께 마련한다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 작업 전 저장소에 설치된 Next.js 문서(서버 컴포넌트 데이터 조회, 캐시)를 확인했다
- [x] 글 테이블 스키마가 저장소의 SQL 파일로 관리된다 (id, 이름, 메시지, 글 비밀번호 해시, salt, 작성 시각, 수정 시각 + 작성 시각 인덱스)
- [x] `npm run db:init`이 `DATABASE_URL`이 가리키는 DB에 스키마를 적용하며, 여러 번 실행해도 안전하다
- [x] 방명록 모듈이 DB 연결(SQL 실행기)을 주입받고, 글 목록 조회 기능을 제공한다
- [x] 글 목록 조회는 작성 시각 최신순이며, 결과에 글 비밀번호 해시·salt가 포함되지 않는다
- [x] `npm test`가 Vitest로 방명록 모듈 테스트를 PGlite(실제 스키마 적용) 위에서 실행한다
- [x] 테스트: 빈 DB에서 빈 목록, 여러 글이 최신순으로 정렬됨, 비밀번호 정보 미포함 (테스트 데이터는 DB에 직접 넣는다)
- [x] 페이지가 항상 최신 목록을 서버에서 렌더링한다(정적 캐시 없음)
- [x] 페이지 상단에 제목과 `개발자: 이동규 (202404265)`가 표시된다
- [x] 글이 없으면 "아직 글이 없습니다"가 표시된다
- [x] 기본 create-next-app 화면 내용이 제거되었다
