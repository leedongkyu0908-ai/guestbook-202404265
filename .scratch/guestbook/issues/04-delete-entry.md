# 04: 글 삭제

**What to build:** 글쓴이가 자기 글의 "삭제" 버튼을 누르면 그 글 안에 글 비밀번호 입력칸이 펼쳐진다. 올바른 글 비밀번호를 넣으면 글이 DB에서 완전히 지워지고 목록에서 사라진다. 비밀번호가 틀리면 "비밀번호가 일치하지 않습니다.", 글이 이미 삭제되었으면 "이미 삭제된 글입니다."가 입력칸 아래에 표시된다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 02 (글 작성)

**Status:** ready-for-agent

- [x] 방명록 모듈에 글 삭제 기능이 있고, 결과를 `성공 / 비밀번호 불일치 / 글 없음`으로 돌려준다 (판정 순서: 글 존재 → 비밀번호)
- [x] 성공 시 글이 DB에서 완전히 지워진다 (소프트 삭제 아님)
- [x] 테스트: 올바른 비밀번호로 삭제하면 목록에서 사라짐
- [x] 테스트: 틀린 비밀번호 → `비밀번호 불일치`, 글 그대로
- [x] 테스트: 없는 id / 이미 삭제된 글 → `글 없음`
- [x] 테스트: A 글의 비밀번호로 B 글을 삭제할 수 없음
- [x] 삭제는 Server Action으로 노출되고, 성공 시 목록을 revalidate한다
- [x] 글 안에서 비밀번호 입력칸이 펼쳐지며(모달·prompt·alert 없음), "취소"로 닫을 수 있다
- [x] 비밀번호 불일치·글 없음 안내가 입력칸 아래에 표시된다
- [x] 03이 먼저 끝났다면: 한 글에서 수정칸과 삭제칸이 동시에 열리지 않는다
- [ ] 개발 서버에서 수동 확인 완료
