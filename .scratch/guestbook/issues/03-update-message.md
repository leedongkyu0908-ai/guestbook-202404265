# 03: 메시지 수정

**What to build:** 글쓴이가 자기 글의 "수정" 버튼을 누르면 그 글 안에 기존 메시지가 채워진 편집칸과 글 비밀번호 입력칸이 펼쳐진다. 올바른 글 비밀번호를 넣으면 메시지가 바뀌고 편집칸이 닫히며, 글에 "(수정됨 · 수정 시각)"이 표시된다. 이름, 작성 시각, 목록 순서는 그대로다. 비밀번호가 틀리면 "비밀번호가 일치하지 않습니다.", 글이 이미 삭제되었으면 "이미 삭제된 글입니다."가 입력칸 아래에 표시되고, 고쳐 쓴 메시지는 유지된다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 02 (글 작성)

**Status:** ready-for-agent

- [x] 방명록 모듈에 메시지 수정 기능이 있고, 결과를 `성공 / 입력값 오류 / 비밀번호 불일치 / 글 없음`으로 돌려준다 (판정 순서: 입력값 → 글 존재 → 비밀번호)
- [x] 성공 시 메시지와 수정 시각만 바뀐다
- [x] 테스트: 올바른 비밀번호로 수정하면 메시지·수정 시각만 바뀌고 이름·작성 시각·목록 순서 유지
- [x] 테스트: 틀린 비밀번호 → `비밀번호 불일치`, 글 변화 없음
- [x] 테스트: 없는 id → `글 없음`
- [x] 테스트: A 글의 비밀번호로 B 글을 수정할 수 없음
- [x] 테스트: 빈 메시지/500자 초과 → `입력값 오류`
- [x] 수정은 Server Action으로 노출되고, 성공 시 목록을 revalidate한다
- [x] 글 안에서 편집칸이 펼쳐지며(모달·prompt·alert 없음), 기존 메시지가 미리 채워진다
- [x] "취소"를 누르면 편집칸이 닫히고 원래 메시지가 그대로다
- [x] 수정된 글에 "(수정됨 · 수정 시각)"이 한국 시간으로 표시된다
- [x] 비밀번호 불일치·글 없음·입력값 오류 안내가 입력칸 아래에 표시되고, 입력 내용이 유지된다
- [x] 04가 먼저 끝났다면: 한 글에서 수정칸과 삭제칸이 동시에 열리지 않는다
